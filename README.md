# CFDICT-Next

An actively maintained version of CFDICT (Chinese-French Dictionary) based on CC-CEDICT, with French definitions generated by an LLM for additional coverage.

## Project Overview

CFDICT-Next creates a new version of CFDICT by:
- Using CFDICT as the authoritative source for French definitions
- Expanding coverage to match CC-CEDICT scope
- Generating missing French definitions using LLMs
- Maintaining a clear precedence: CFDICT > LLM-confident > LLM-review

## Key Features

- **Authoritative Base**: CFDICT remains the source of truth
- **LLM-Generated Coverage**: French definitions for missing entries
- **Two Output Dictionaries**: 
  - Confident dictionary (CFDICT + high-confidence LLM)
  - Full dictionary (CFDICT + all LLM entries)
- **Scope Tracking**: Each release tied to specific CC-CEDICT version
- **Reproducible Builds**: Nix-based development environment
- **Automated Release Pipeline**: GitHub Actions workflow

## Development Setup

### Prerequisites
- Nix with Flakes enabled ([instructions](https://nixos.wiki/wiki/Flakes))
- direnv ([installation](https://direnv.net/docs/installation.html))

### Getting Started
```bash
# Clone the repository
git clone <repository-url>
cd CFDICT-Next

# Allow direnv to load the environment
direnv allow

# Enter the development shell
nix-shell
# or simply:
# direnv reload  # if already in shell

# Verify Python is available
python3 --version
```

### Development Workflow
1. Make changes to source data or code
2. Run validation: `python src/validation.py`
3. Assemble dictionaries: `python src/assembly.py`
4. Run tests: `pytest`

## Release Process
Releases are automated via GitHub Actions:
1. Triggered by updates to: `cfdict.u8`, `confident.json`, `review.json`
2. Runs assembly and validation
3. Produces: 
   - Confident dictionary (.u8)
   - Full dictionary (.u8)
   - Scope information (included with release)
4. Publishes as GitHub Release

## Configuration
Environment variables can be set in `.envrc` or shell:
- `CFDICT_NEXT_ENV`: Environment (development/staging/production)
- `LLM_MODEL`: LLM model to use for generation
- `LLM_PROMPT_VERSION`: Prompt version for generation
